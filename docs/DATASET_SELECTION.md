# MVP 데이터셋 및 대표 질문

기준일: 2026-11-03

이 문서는 용인시 생활여가·문화·체육 범위에서 2~3일 MVP에 사용할 데이터셋 3종과 대표 질문 3개를 고정한다. 실제 수집 건수와 품질은 수집 단계에서 다시 검증하며, 메타데이터만 확인한 상태를 실제 수집 완료로 표시하지 않는다.

## 선정 데이터셋

### 1. 수지구청 홈페이지 생활체육프로그램 정보

- 제공기관: 경기도 용인시
- 공공데이터포털 ID: `15136680`
- 형식: CSV
- 공개 건수: 276행
- 공개 데이터 기준: 파일명 기준 2025-09-16
- 갱신 특성: 기관 페이지에서 수시 제공되는 파일 데이터
- 원본 안내: <https://www.data.go.kr/data/15136680/fileData.do>
- 제공 페이지: <https://www.sujigu.go.kr/lmth/04life0703.asp>
- 주요 필드: 관리번호, 운영장소, 강의명, 강의 시작일·종료일, 교육 요일, 운영 시간, 모집 대상, 신청 인원, 대기 인원, 접수 기간, 공지사항
- 선정 이유: 실제 프로그램 검색 질문을 검증할 수 있고 CSV 수집·정제 경로를 확인할 수 있다.
- 한계: 수지구 범위이며, 공개 페이지의 다운로드 방식과 최신 파일 구조를 수집 단계에서 확인해야 한다.

## 대표 질문 3개

### 질문 1

“수지구에서 특정 요일과 이용 대상에 맞는 생활체육 프로그램은 무엇인가?”

- 데이터셋: 생활체육프로그램 정보
- 필수 필드: 강의명, 운영장소, 교육 요일, 운영 시간, 모집 대상, 접수 기간, 신청·대기 인원
- 계산: 요일·대상 필터, 접수 기간과 수집일 비교
- 출력: 프로그램명, 장소, 시간, 모집 대상, 접수 정보, 데이터 기준일과 출처

### 질문 2

“용인시에서 주말에 이용할 수 있는 무료 공공 체육·문화시설은 어디인가?”

- 데이터셋: 공공시설개방정보
- 필수 필드: 시설명, 시설유형, 주말 운영시간, 휴관일, 유료 여부, 주소, 전화번호, 홈페이지
- 계산: 용인 범위, 무료, 주말 운영시간 존재 여부 필터
- 출력: 시설명, 유형, 주말 운영시간, 주소, 연락처, 데이터 기준일과 출처

### 질문 3

“용인시 구별로 운동시설이 있는 도시공원 수와 총면적은 얼마인가?”

- 데이터셋: 도시공원정보
- 필수 필드: 관리번호, 공원명, 공원구분, 주소, 공원면적, 운동시설
- 계산: 주소에서 처인구·기흥구·수지구 추출, 운동시설 존재 여부 판정, 구별 건수와 면적 합계
- 출력: 구별 공원 수, 총면적, 계산 기준, 데이터 기준일과 출처

## 공통 수집·검증 규칙

- 원본 응답 또는 파일은 `data/raw/`에 변경 없이 보존한다.
- `collected_at`과 원본의 `reference_date`를 별도 필드로 관리한다.
- 파일 해시, 출처 URL, HTTP 상태, 수집 실행 ID를 기록한다.
- 용인 범위 필터 전후 건수를 기록한다.
- 스키마, 필수값, 건수 검증을 통과한 결과만 운영 DB 반영 대상으로 삼는다.
- 갱신 실패 시 기존 정상 운영 데이터를 교체하지 않는다.
- 실제 수집 전에는 공개 메타데이터 건수를 운영 데이터 건수로 표시하지 않는다.
